# 官网在线编辑：集成边界与分期

本轮为独立原型，不是已部署的官网后台。用户于 2026-10-21 确认：网页编辑者无需接触 Git；管理员文字编辑先行，随后扩展样式与公众投稿。服务器可保存内容仓库，再单独同步 GitHub。

- 精确阅读基线：exomind-team/agi-society-cn，b719c21c079f8f1c1026be209aac96206c67864e。

## 四个不同动作

1. 保存草稿：私有工作数据；不得进入公开 Git 历史、公开静态目录或预览索引。
2. 发布内容版本：经确认将指定草稿保存为可发布的内容提交。原型中不意味着正式站已经更新。
3. 网站上线：对明确提交构建、校验、生成不可变产物，再切换服务版本。构建失败保留旧站；不得谎报成功。
4. 同步公开托管：只同步获准公开的内容与代码，独立状态、独立失败与重试。离线不阻止本地草稿；同步失败不应抹去已保存内容。

GitHub 与服务器不可同时未经协调地成为权威写入端。推荐服务器担任编辑写入端，GitHub 外部改动先进入导入检查；相同页面冲突交给人确认，不自动覆盖或强推。

## 第一阶段的文字边界

VitePress Markdown 不是天然无执行能力的纯文本格式。页面可能包含 Vue 组件、脚本、模板表达式及影响站点行为的 frontmatter。

- 首期明确允许编辑的页面和文字区域；保持原有元数据、链接与组件不被静默删除。
- 不把全文 Markdown 输入框宣称为普通人所见即所得编辑器。
- 接受 HTML/Vue/脚本、开放样式与任意组件是后续独立能力，不能顺手扩权。
- 预览必须说明是否与最终站点同一渲染链；转义文本预览只能证明文字内容，不证明 VitePress 最终样式。
- 返回修改时显示增加、删除及文字标记，颜色只是辅助。技术错误转为可理解操作建议，保留用户输入。

## 上线前必须接上的环节

管理员身份和会话、授权与 CSRF 防护、HTTPS、审计、媒体来源与访问控制、隔离构建、备份恢复、并发编辑冲突、公开托管同步凭据、真实浏览器验收。仅监听本地与模拟身份都不等于生产管理员认证。

首个实际验收任务应为：选择已批准页面 → 修改正文 → 保存草稿 → 重开仍可恢复 → 查看增删 → 预览 → 明确发布 → 第二个编辑者旧版本保存被拦并保留输入 → 恢复上一版形成新记录。之后才增加图片、样式、审核人角色与公众投稿。
