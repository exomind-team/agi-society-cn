# NARS-Pong

> **层级**：A3. 框架与应用 — 用 NARS 控制游戏 NPC 的 Unity3D Demo

- 全名：**NARS-Pong**
- 编程语言：Tcl（实际是 Tcl 包装 + Java 进程调用 OpenNARS/ONA）
- 仓库：<https://github.com/ccrock4t/NARS-Pong>
- 维护者：Christian Hahm（GitHub ccrock4t）
- 仓库平台创建日：2020-08-27；最后一次 push：2023-11-01
- Stars：7

## 项目简介

仓库 README：「NARS Pong in Unity3D」。运行说明要求 Cygwin 与 Java 环境：Java 用于驱动 OpenNARS / ONA，Unity3D 渲染游戏画面，Tcl 编排游戏循环——属于用 NARS 推理机驱动游戏 NPC 的典型 demo。

参考条目：
- OpenNARS：<https://github.com/opennars/opennars>
- ONA：<https://github.com/opennars/OpenNARS-for-Applications>
- NARS-Python：<https://github.com/ccrock4t/NARS-Python>
