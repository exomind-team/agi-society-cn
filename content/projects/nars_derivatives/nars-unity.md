- 全名：**NARS-Unity**
- 编程语言：C#
- 仓库：<https://github.com/ccrock4t/NARS-Unity>

- 许可证：MIT
- 仓库平台创建日：2018 年前后；最后一次 push：2026-06-24；stars：4

## 项目简介

仓库 README：「A C# NARS for Unity game engine. Originally ported from NARS-Python v0.4」。使用方式：`NARSAgent.cs` 挂到 Unity 游戏对象，用 `SendInput()` 输入 NARS，C# 函数定义 NARS 操作。

## 收录与归属

本页属于 [[index|NARS衍生项目]]。是同作者 ccrock4t 在 [[nars-pong|NARS-Pong]] 之后把 NARS 移植到 Unity 的 C# 重写版。构成 ccrock4t 的 NARS 游戏/应用实验系列的"纯 C# Unity 接口"端，与 Tcl/Unity3D 版 NARS-Pong（仓库风格不同）并存。
