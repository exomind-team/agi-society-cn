## 项目简介

项目方在仓库描述中写到：「A NARS implemented as a GPT model prompted to invoke reasoning steps, with NARS-based memory and control machinery implemented in Python.」——以 GPT 模型的提示方式一步步调用推理步骤，把 NARS 的记忆与控制机制用 Python 落地。

## 收录与归属

本页属于 [[index|NARS衍生项目]]。它不直接重写 NARS 推理引擎内核，而是把 NARS 的功能（记忆、控制、推理循环）借大模型的提示工程重新搭建——属于"基于 NARS 的衍生应用"。
