# NARS 实现资料采集表（格式草案）

> 建立日期：2026-09-19
>
> 用途：为 `content/projects/nars_impl/` 的后续内容补全提供统一采集格式。本表只记录可由仓库、作者/组织页面、发布页或可复现实验直接核验的信息；没有可靠证据的字段写“未知”或“待核验”，不根据仓库活跃度推测维护状态。

## 建议字段

| 字段 | 填写规则 |
| --- | --- |
| 项目名称 | 页面展示名称；必要时附版本/代际 |
| 实现版本/代际 | 例如 OpenNARS 1.x、NAL 版本或项目自身版本；无可靠资料则写“未知” |
| 编程语言 | 以仓库或发布元数据为准 |
| 作者或维护组织 | 以项目主页、仓库说明或发布信息为准 |
| 代码仓库 | GitHub/Gitee 等直接链接；多个仓库说明用途 |
| 许可证 | 仅在 LICENSE、仓库元数据或官方说明中确认后填写 |
| Narsese / NAL 覆盖范围 | 只填写项目明确声明或可复现验证的范围 |
| 运行方式或在线 Demo | 安装命令、发行包、教程、在线 Demo；注明最后核验日期 |
| 维护状态 | 仅使用“活跃开发 / 维护中 / 暂停 / 归档 / 未知”等有证据支持的表述 |
| 最后核验日期 | 每次实际打开来源或复现实验后更新 |
| 备注 | 记录版本差异、镜像、历史资料和待补证据 |

## 公开页面回填建议

每个实现页面可以在项目简介后新增一个“资料卡”表格，字段顺序固定为：

| 项目名称 | 实现版本/代际 | 编程语言 | 作者或维护组织 |
| --- | --- | --- | --- |
| 示例：NARust | NARust-158 | Rust | Tessergon（现有页面记录） |

| 代码仓库 | 许可证 | Narsese / NAL 覆盖范围 | 运行方式或在线 Demo |
| --- | --- | --- | --- |
| 直接链接 | 未知（待核验） | 未知（待核验） | [[narust|现有页面中的在线 Demo]] |

| 维护状态 | 最后核验日期 | 备注 |
| --- | --- | --- |
| 待核验 | 待补 | 不根据仓库提交频率推断 |

完成一项核验后，再将表格复制到对应的 `content/projects/nars_impl/*.md` 页面，并删除与新资料冲突的旧 `todo`。NAL 7–9、非公理控制等理论内容不在本轮资料卡范围内，按既定计划另行处理。
