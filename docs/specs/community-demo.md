# 精简社区融合演示

本轮社区位于 `/community`，借鉴 Discourse 的话题组织，但不是已部署的 Discourse。没有帐号、SSO、网络发帖或后台服务。

## 阅读闭环

人物页 → 论文／报告 → 引用本页或选中段落 → 研究讨论／实验复现／Wiki 改进 → 本地草稿 → 按引用回到 Wiki。引用保存条目路径、段落定位、原文摘录和 `wiki-people-community-20261020-v1` 快照版本。段落定位对应该快照，不承诺在任意后续改版中永久稳定。

界面只先显示三类入口；编辑器按需展开。示例是演绎，不是真实研究者的新发言。讨论结果必须核验后再由维护者合入 Wiki，本地保存不改变论文、师承或报告事实。

草稿使用当前浏览器 localStorage，最多保留最近 100 份；保存失败明确提示导出，不伪报成功。支持单份 JSON 导出，不自动上传。不同浏览器及 file:// 存储隔离行为不同，应导出重要草稿。

原始转写 `discovery: unlisted` 不生成引用按钮，不进入离线搜索、目录或知识地图。隐藏索引不是访问控制。

## 验证

运行 `node tests/community-drafts.test.mjs`，以及根路径预览构建后的关系与内容保留测试。离线打包测试另覆盖人物到论文、段落引用、保存草稿、返回 Wiki、相关本地讨论反链和存储失败。真实浏览器视觉、触控与下载兼容性须另验。
